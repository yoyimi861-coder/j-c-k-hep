 # 한·중·일 유학생 학습 도우미

## 이 프로그램은 한국, 중국, 일본 유학생을 위한 학습 도우미 웹사이트입니다.

### 환영합니다!

**한·중·일 유학생 학습 도우미**는 

유학생들이 학교생활에서 자주 사용하는 표현과 번역 기능을 쉽게 이용할 수 있도록 만든 웹사이트입니다.

- 한국어, 중국어, 일본어 번역 기능을 제공합니다.

- 자주 사용하는 학교 표현을 확인할 수 있습니다.

- 필요한 표현을 즐겨찾기에 저장할 수 있습니다.

- 다크 모드를 지원합니다.

- 교수님께 보내는 이메일 예시를 제공합니다.

- 모바일 환경에서도 사용할 수 있습니다.

## 주요 기능

|기능|설명|

|-|-|

|번역 기능|한국어·중국어·일본어 표현 번역|

|표현 모음|유학생 생활에서 자주 사용하는 표현 제공|

|즐겨찾기|필요한 표현 저장|

|다크 모드|화면 밝기 변경|

|메일 예시|교수님 이메일 작성 도움|

|모바일 지원|스마트폰에서도 사용 가능|

## 사용 방법

1. 원하는 언어를 선택합니다.

2. 단어나 문장을 입력합니다.

3. 번역 결과를 확인합니다.

4. 필요한 표현은 즐겨찾기에 저장합니다.

- HTML

- CSS
